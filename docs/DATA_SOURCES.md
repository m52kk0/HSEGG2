## Зарплаты выпускников

Формат: `data[регион][код] = { y1: [...], y5: [...] }`, где

- `y1` — выпуск 2023 года, то есть примерно через год после выпуска;
- `y5` — выпуск 2019 года, примерно через пять лет;
- в каждом наборе три значения: средняя зарплата (₽), доля трудоустроенных (%), число выпускников;
- зарплата измерена в 2024 году;
- значения могут быть `null` — тогда интерфейс пишет «нет данных», а не подставляет ноль.

Ключ `"RU"` — данные по всей стране. Если по региону данных нет, карточка показывает значения
по России и **явно подписывает это**: «по России».

## Проходные баллы: почему они демо

Открытого API или машиночитаемого реестра проходных баллов в России не существует. Вузы публикуют
их на своих сайтах в произвольном формате — от PDF до картинок. Реестр Рособрнадзора для этой
задачи недоступен. Задание хакатона разрешает тестовые данные, поэтому:

1. `scripts/generate-demo-programs.ts` с **фиксированным seed 20260917** создаёт
   `data/snapshot/programs.demo.json`. Результат детерминирован: одинаковый seed даёт побайтово
   одинаковый файл, и CI проверяет, что сгенерированное совпадает с закоммиченным.
2. Каждому вузу назначается 6–20 направлений **правдоподобно по названию**: политехнический
   получает инженерию и IT, педагогический — 44.\*, медицинский — 30–34, аграрный — 35 и 36,
   лингвистический — 45 и гуманитарные, классический университет — смесь.
3. Ведомственные вузы (МВД, МЧС, ФСБ, ФСО, ФСИН, военные) **исключены**: у них особый порядок приёма.
4. Уровень проходных зависит от популярности направления (IT, медицина, международные отношения —
   выше), региона (Москва +34, Санкт-Петербург +26, крупные регионы +10) и статуса вуза
   (федеральные и национальные исследовательские — выше). Тренд за три года — от −10 до +15.
   Медиана прогноза — около 221 балла.
5. **Каждая цифра помечена `isDemo: true`**, и интерфейс показывает рядом метку «Демо» с тултипом
   «Проходные баллы в прототипе — тестовые данные».

Вузы демо-сценария закреплены жёстко: НГТУ им. Р. Е. Алексеева (`Q4318652`) и ННГУ
им. Н. И. Лобачевского (`Q492766`) получают ровно тот набор направлений и те проходные, которые
нужны сценарию защиты. Это закреплено отдельным тестом
(`packages/data/src/__tests__/generator.test.ts`).

### Как добавить реальные проходные

1. Найди значения на сайте приёмной комиссии — обычно раздел «Приём» → «Результаты прошлых лет».
2. Добавь запись в `data/snapshot/programs.real.json`:

```json
[
  {
    "id": "Q4318652-15.03.04",
    "universityId": "Q4318652",
    "code": "15.03.04",
    "name": "Автоматизация технологических процессов и производств",
    "budgetPlaces": 65,
    "exams": ["math", "russian", ["physics", "informatics"]],
    "minScores": { "math": 45, "russian": 44, "physics": 41, "informatics": 43 },
    "cutoffs": { "2023": 214, "2024": 220, "2025": 225 },
    "isDemo": false
  }
]
```

3. При совпадении `universityId` + `code` реальная запись **перекрывает** демо и получает
   `isDemo: false` — метка «Демо» с этой цифры исчезает автоматически.
4. Запусти тесты: `pnpm test` — снимок проверяется схемами zod и на ссылочную целостность.

**Не выдумывай значения.** Метка «Демо» — единственное, что отличает честный прототип
от вранья на защите.

## Вакансии: почему «Работа России», а не hh.ru

hh.ru закрыл публичный поиск вакансий для неавторизованных клиентов: без токена приложения
эндпоинт `/vacancies` не работает. Оформление доступа требует регистрации приложения и модерации.

Открытое API «Работа России» (opendata.trudvsem.ru) не требует ключа вообще:

```
http://opendata.trudvsem.ru/api/v1/vacancies/region/{код региона}?text={запрос}&limit=20
```

Ответ приходит в `results.vacancies[].vacancy` с полями `job-name`, `salary_min`, `salary_max`,
`company.name`, `vac_url`, `creation-date`. Прокси нормализует их и кэширует на 6 часов в памяти
(LRU) и в SQLite. Таймаут — 4 секунды.

## Известные ограничения данных

| Ограничение | Как проявляется | Что сделано |
| --- | --- | --- |
| Список вузов Wikidata неполный | Некоторых вузов нет вовсе | Указано здесь и на первом экране |
| В Wikidata у части вузов в поле «город» стоит район | «Козья слобода, Республика Татарстан» | В плане рядом с городом показывается регион |
| Координат нет у части вузов | Близость к дому не учитывается для них | Расчёт близости пропускается, план строится |
| Зарплаты не по всем регионам и кодам | «нет данных» или фолбэк на Россию | Фолбэк подписан явно |
| Зарплаты измерены в 2024 году | Данные не «сегодняшние» | Подписано под блоком зарплат |
| Проходные тестовые | Все цифры помечены «Демо» | См. выше |
| Только общий конкурс на бюджет | Квоты, БВИ и внутренние экзамены не считаются | Указано в README и на экранах |

## Обновление данных

```bash
pnpm gen:programs   # перегенерировать демо-программы и stats.json
pnpm test           # проверить снимок схемами и на целостность
```

Фоновое обновление списка вузов из Wikidata предусмотрено флагом `REFRESH_WIKIDATA=true`,
по умолчанию выключено: неудачный ответ не должен затирать рабочий снимок.
