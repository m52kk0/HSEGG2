# Дизайн-система

Корпоративный минимализм: 95% экрана — белый и оттенки серого, цвет только как сигнал. Все
значения объявлены в `apps/web/src/styles/tokens.css`. **Хардкод-цветов в компонентах нет** —
это проверяет stylelint правилом `color-no-hex`.

Витрина всех компонентов и токенов — `/design` (только в dev-режиме: `pnpm dev`, затем
<http://localhost:5173/design>).

---

## UX-принципы

Порядок важен: при конфликте выигрывает тот, что выше.

1. **Одно главное действие на экран** — одна синяя кнопка. Остальное — secondary или text.
2. **Сначала ответ, потом детали**: вердикт → причина → данные. План начинается фразой
   «Бюджет почти гарантирован», а не таблицей.
3. **Код направления всегда рядом с названием**: `15.03.04 · Автоматизация технологических
   процессов и производств`. Абитуриенты, родители и приёмные комиссии говорят кодами; поиск
   работает и по коду, и по названию.
4. **Термины — только с пояснением.** «Приоритет», «согласие на зачисление», «допнабор», «УГСН»
   идут со знаком «?» и понятным текстом. Где можно — обычные слова: рядом с «Приоритет 1» стоит
   «Хочу больше всего».
5. **Цвет никогда не единственный носитель смысла**: цветная точка всегда с словом («● Запасной»),
   вердикт — фразой, лучшее значение в сравнении — жирным и точкой акцента.
6. **Нет пустых экранов**: у каждого пустого состояния есть текст и действие.
7. **Ошибки предупреждаются заранее**, а не после действия: кнопка «Дальше» неактивна, пока нет
   ответа; предупреждения о рисках появляются сразу после правки плана.
8. **Числа — с единицами и знаком**: «+12 баллов», «72 тыс. ₽», «82% трудоустроены», «−8».
9. **Мобильные первыми**: 360px без горизонтального скролла, тач-цели ≥ 44px.
10. **Всё управляется с клавиатуры**, фокус видимый.

Пункты 5, 9 и 10 проверяются автотестами — см. [TESTING.md](TESTING.md).

## Токены

```css
:root {
  --bg: #ffffff;
  --bg-secondary: #f7f8fa;
  --text-primary: #000000;
  --text-secondary: #6b6b6b;   /* #999 не проходит контраст AA для мелкого текста */
  --text-tertiary: #a3a3a3;    /* только плейсхолдеры и неактивное */
  --border: #e5e5e5;

  --accent: #0066d6;           /* затемнён относительно #0077FF из ТЗ, см. ниже */
  --accent-hover: #0052b0;
  --accent-light: #f0f7ff;

  --zone-safe: #00b341;
  --zone-target: #ffa800;
  --zone-reach: #f5222d;
  --zone-safe-light: #e8f9ee;  /* фоны плашек, производные от сигнальных цветов */
  --zone-target-light: #fff6e5;
  --zone-reach-light: #fff1f0;

  --radius-s: 8px;
  --radius-m: 12px;
  --space: 8px;                /* все отступы кратны 8, допускается 4 */
  --max-width: 1080px;
  --font: 'Inter', system-ui, sans-serif;

  --motion: 180ms;             /* 0ms при prefers-reduced-motion */
  --tabbar-height: 60px;
}
```

**Про синий.** ТЗ задаёт `#0077FF`, но он даёт с белым текстом контраст 4,13:1 — ниже порога
WCAG AA (4,5:1), и axe находил нарушение уровня serious на каждой кнопке. `#0066D6` — тот же
оттенок при 5,4:1. Подробнее — в [DECISIONS.md](DECISIONS.md#3-синий-затемнён-0066d6-вместо-0077ff).

**Про зоны.** Цвета зон используются как фон только в светлых вариантах (`--zone-*-light`) с тёмным
текстом. Белый текст на зелёном и оранжевом не проходит AA, поэтому номера приоритетов в полосе зон
написаны тёмным на светлой заливке с цветной рамкой.

## Типографика

| Стиль | Размер / вес | Где |
| --- | --- | --- |
| H1 | 28 / 700, letter-spacing −0.02em | вердикт, заголовок экрана |
| H2 | 20 / 600 | название вуза, заголовок блока |
| H3 | 16 / 600 | подзаголовок внутри блока |
| Body | 15 / 400, line-height 1.5 | основной текст |
| Small | 13 / 400 | пояснения, источники, метаданные |
| Data | 24 / 700, `font-variant-numeric: tabular-nums` | крупные числа: баллы, места |

Шрифт Inter подключён локально через `@fontsource/inter` — внешних CDN нет, контейнер работает
офлайн. Все числа выводятся моноширинными цифрами, чтобы столбцы не дрожали.

## Компоненты

Все живут в `apps/web/src/ui/`. У каждого есть состояния: default, hover, focus-visible, active,
disabled, loading — где они осмысленны.

| Компонент | Особенности |
| --- | --- |
| `Button` | Ровно три вида: `primary` (фон accent, белый текст), `secondary` (обводка), `text`. Больше видов нет и не появится. Минимальная высота 44px; у `text` — 44px даже в размере `s`, хотя визуально она компактная. |
| `IconButton` | 44×44, обязательная подпись `label` для скринридера (↑ ↓ ✕ в плане). |
| `ZoneBadge` | Точка 8px + слово + опционально запас: «Запасной · +19». Точка скрыта от скринридера — она дублирует слово. |
| `DemoTag` | Серая метка «Демо» с тултипом «Проходные баллы в прототипе — тестовые данные». |
| `Card` | Фон `--bg`, рамка 1px, радиус 12, **без теней**. Варианты: `flat` (серый фон), `accent` (голубой). |
| `Tooltip` | Кружок «?» 18px, но тач-цель 44×44 за счёт отрицательных полей. Открывается по клику, ховеру и фокусу; закрывается по Escape, клику вне и потере фокуса. |
| `Term` | Термин вместе с тултипом — так оформлены все понятия приёма. |
| `Tile` | Плитка выбора (предметы, интересы, режим региона). Показывает номер порядка выбора. |
| `Chip` | Фильтры и выбранные регионы, `aria-pressed`. |
| `Input`, `NumberInput`, `Combobox` | Ошибка связана с полем через `aria-describedby`, `aria-invalid`. Combobox — выбор региона с поиском по 87 значениям. |
| `Switch`, `Checkbox` | Подпись кликабельна целиком. |
| `ProgressBar` | `role="progressbar"` с текстовой подписью «Шаг 2 из 4». |
| `Tabs` | `role="tablist"`, используется для периода в аналитике. |
| `Alert` | `info` / `warning` / `danger` с иконкой и опциональным действием. |
| `Skeleton` | Заглушка при загрузке вакансий и чанков экранов. Анимация отключается при `prefers-reduced-motion`. |
| `EmptyState` | Заголовок, текст и действие — пустых экранов без выхода не бывает. |
| `MiniChart` | Чистый SVG: проходные по годам, пунктир прогноза, горизонталь «твой балл». Тяжёлых библиотек графиков в проекте нет. Полное текстовое описание в `<title>` для скринридера. |

Иконки — `lucide-react`, только функциональные: стрелки, закрыть, плюс, вопрос, внешняя ссылка,
компас в логотипе. Декоративных нет.

## Печать

`@media print` убирает навигацию, кнопки и интерактив (класс `no-print`), раскрывает содержимое
и дописывает адреса ссылок. Кнопка «Скачать план» — это `window.print()`: отдельного PDF-бэкенда
в прототипе нет и не нужно.

## Анимация

Одна длительность на весь интерфейс — `--motion: 180ms`. Анимируются только появление строк плана
и раскрытие блоков. При `prefers-reduced-motion: reduce` переменная становится `0ms`, а анимации
скелетона и спиннера замедляются или отключаются.
