# Cursus — навигатор поступления

**Не гадай — проложи курс.**

Справочники показывают, куда можно поступить. Cursus отвечает на другой вопрос: **как поступить так,
чтобы не остаться без бюджета**. Сервис собирает план подачи документов по правилам приёма 2026 года —
до 5 вузов и до 5 направлений в каждом, — расставляет приоритеты, показывает запас баллов к прогнозу
проходного и честно говорит, где план рискует развалиться.

## Быстрый старт

Один контейнер, внутри и фронт, и API:

```bash
docker build -t cursus . && docker run -p 8080:8080 -v cursus-data:/data cursus
```

Открой <http://localhost:8080>.

Вариант для разработки:

```bash
pnpm install && pnpm dev
```

Фронт поднимется на <http://localhost:5173>, API — на <http://localhost:8080>. Подробности —
в [docs/DEPLOY.md](docs/DEPLOY.md).

## Главный сценарий

1. **4 вопроса** — какие ЕГЭ сдаёшь, сколько баллов, что интересно, где готов учиться.
2. **Вердикт одной фразой**: «Бюджет почти гарантирован» или «Высокий риск остаться без бюджета».
3. **План**: до 5 вузов, внутри каждого — пронумерованные приоритеты с зоной и запасом баллов.
4. **Предупреждения о рисках**: нет запасного варианта; порядок обесценивает мечту; вузы из разных
   регионов — считай общежитие и дорогу.
5. **Карточка направления**: график проходных 2023–2025 с пунктиром прогноза и линией твоего балла,
   зарплаты выпускников, живые вакансии, похожие направления с разницей одной фразой.
6. **Сравнение** до 3 направлений по одинаковым строкам.
7. **План Б** — что делать, если не пройдёшь никуда: 4 ветки со сроками, плюсами, минусами и чек-листом.

Экран `/admin` — обезличенная аналитика: воронка, топ открываемых направлений и топ сравниваемых пар.

## Чем отличается от существующих сервисов

| | Vuzopedia, Postupi.online | Госуслуги | **Cursus** |
| --- | --- | --- | --- |
| Каталог вузов и направлений | да | нет | нет, это не каталог |
| Проценты «шанс поступления» | да | нет | **нет — по открытым данным их нельзя посчитать честно** |
| Готовый план подачи с приоритетами | нет | нет | **да** |
| Объяснение, почему такой порядок | нет | нет | **да** |
| Запас баллов к прогнозу проходного | нет | нет | **да, «+12» или «−8»** |
| Предупреждения о рисках плана | нет | нет | **да** |
| План Б со сроками | нет | нет | **да** |
| Зарплаты выпускников и живые вакансии | частично | нет | **да, Росстат и «Работа России»** |
| Подача документов | нет | да | нет — это работа Госуслуг |
| Регистрация и персональные данные | да | да | **нет** |

Ключевой инсайт, на котором построен продукт: по правилам приёма зачисляют на направление
с **наивысшим приоритетом, на который абитуриент проходит по конкурсу**. Значит поставить мечту
первой — бесплатно, и порядок должен отражать желание, а не страх. Большинство абитуриентов
об этом не знает и ставит первым «то, куда точно пройду».

## Стек

| Слой | Технологии |
| --- | --- |
| Фронт | Vite, React 18, TypeScript, React Router, Zustand |
| Бэкенд | Hono на Node 24, `node:sqlite`, zod |
| Пакеты | `@cursus/core` — алгоритм; `@cursus/data` — снимок данных |
| Тесты | Vitest, Testing Library, Playwright, `@axe-core/playwright` |
| Качество | ESLint (typescript-eslint, react-hooks, jsx-a11y), Prettier, stylelint |
| Контейнер | multi-stage Dockerfile, `node:24-alpine`, 245 МБ |

Внешних CDN, шрифтов и скриптов нет: Inter подключён локально, контейнер работает офлайн.

## Структура

```
cursus/
├─ apps/
│  ├─ web/            # интерфейс: экраны, UI-кит, дизайн-токены
│  └─ api/            # Hono: каталог, прокси вакансий, аналитика
├─ packages/
│  ├─ core/           # чистый алгоритм: баллы, прогноз, зоны, buildPlan
│  └─ data/           # загрузка и индексация снимка, мерж demo + real
├─ data/
│  ├─ snapshot/       # направления, вузы, регионы, зарплаты, проходные
│  └─ content/        # редакционные тексты направлений
├─ scripts/           # генератор демо-данных, smoke-проверка контейнера
├─ e2e/               # Playwright: сценарии и доступность
└─ docs/              # документация
```

## Ограничения прототипа

Честно, чтобы на защите не было сюрпризов:

- **Проходные баллы — тестовые.** Открытого API с проходными не существует. Данные сгенерированы
  детерминированным скриптом и правдоподобны по профилю вуза, региону и популярности направления.
  Каждая такая цифра помечена в интерфейсе меткой **«Демо»**. Реальные значения вносятся вручную
  в `data/snapshot/programs.real.json` и перекрывают демо.
- **Учитывается только общий конкурс на бюджет.** Целевая, особая и отдельная квоты, поступление
  без вступительных испытаний и внутренние экзамены — вне скоупа.
- **Список вузов из Wikidata неполный** (578 вузов) и местами содержит район вместо города.
- **Прогноз — не вероятность.** Это продолжение тренда за три года, и так и написано на экране.
- **Даты приёмной кампании — по правилам 2026 года**, даты 2027 года уточняются.
