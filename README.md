# Cursus — стартовый набор для Claude Code

1. Создай пустую папку проекта (например `cursus`), положи туда этот набор.
2. Запусти Claude Code в этой папке и дай ему команду:

   > Прочитай CLAUDE_CODE_TZ.md целиком и выполни проект по фазам из раздела 12. Данные для снимка лежат в ./data — перенеси их в data/snapshot/. После каждой фазы проверяй Definition of Done и делай коммит.

3. Файлы в `data/` — снимок реальных данных на 17.09.2026:
   - `directions.json` — 276 направлений (коды ОКСО);
   - `salaries.json` — зарплаты и трудоустройство выпускников по 87 регионам и РФ;
   - `regions.json` — регионы с кодами API «Работа России»;
   - `universities.json` — 578 вузов из Wikidata;
   - `vacancies_sample_nn.json` — пример ответа API «Работа России».
